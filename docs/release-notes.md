WireDesk turns a Mac into a Windows second display over dedicated Ethernet. Native Mac/Windows interfaces, pairing code/file import, automatic TLS identity provisioning, saved configuration and reconnect, 60/120 profiles, dedicated interface binding, and signed OTA updates.

Mac: universal Apple Silicon/Intel application, macOS 13+. Windows: x64 per-user installer and portable package. Configure one Virtual Display Driver monitor separately, then select Extend in Windows display settings. Internet is needed only for updates.

This initial experimental release does not carry an Apple Developer ID/notarization or Windows Authenticode certificate. OTA archives are signed with Ed25519. Physical Windows→Ethernet→Mac 120 FPS and end-to-end latency have not yet been measured; see the validation documents. Keep OS security protections enabled.
